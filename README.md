# Poko

Poko est une application web de gestion de budget personnel.

## Application

https://joseph-bigot.github.io/poko/

## Technologies

- Angular
- TypeScript
- SCSS
- IndexedDB
- GitHub Pages

## Fonctionnalités

- Gestion des revenus
- Gestion des charges
- Gestion des dépenses
- Gestion du budget
- Synthèse financière
- Gestion des objectifs d’épargne
- Historique des mois
- Bons plans
- Mode clair / sombre
- Interface responsive
